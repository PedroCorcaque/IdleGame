# 🪓 Lenhador Idle

Um joguinho idle no estilo dos "playable ads": você coleta itens, vende, ganha dinheiro e desbloqueia o mundo ao redor. Feito para passar o tempo, com frases carinhosas e muitos pinguins. 🐧💜

## Como jogar

- **Mover:** arraste o dedo na tela (celular) ou use as setas / WASD (computador).
- **Coletar:** chegue perto de um item e o personagem coleta sozinho.
- **Vender:** leve a carga até a casinha para transformar tudo em dinheiro.
- **Melhorar:** fique em cima dos tapetes coloridos para gastar o dinheiro em upgrades.

## Fases

| Fase | Cenário | Item | Vende em |
|------|---------|------|----------|
| 1 | Floresta violeta | Madeira | Casinha |
| 2 | Lago gelado | Peixe | Iglu |
| 3 | Berçário | Ovo de pinguim | Berçário |

Em cada fase há 4 upgrades: nova área, mochila maior, ajudante e ferramenta mais forte. A partir da fase 2, os ajudantes são pinguins.

## Como rodar

O jogo inteiro está em um único arquivo, sem dependências para instalar.

1. Baixe o arquivo `index.html`.
2. Abra no navegador (duplo clique).

## Feito com

- HTML, CSS e JavaScript puro
